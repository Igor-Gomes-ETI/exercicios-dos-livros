# Resoluções dos leitores

Crie uma pasta com seu nick do GitHub. Mantenha as resoluções propostas em `livros/` preservadas.

Caminho: `alternativas/seu-nick/volume-1/capitulo-NN/exercicio-NN/`.

Coloque o código ou resposta conceitual e um README nessa pasta. Veja o [passo a passo completo](../CONTRIBUTING.md) e o [modelo do leitor](../modelos/solucao-do-leitor.md). O nick `seu-nick` e os números `NN` são espaços para preencher, não pastas que você deve usar literalmente.
